# Character pictures / 立绘

The repository has no character pictures. Put your own pictures in this folder. If a file is missing, the page leaves that spot empty and works as usual.

1. Use these file names. `normal.webp` is the usual picture, and the chat avatars also use it. `happy.webp` and `jealous.webp` follow the mood. `sleepy.webp` shows when the bot is asleep or paused, and on the login card. `browsing.webp` shows while it browses.
2. The overview page shows the picture large. A tall picture with a transparent background, 600 px high or more, looks best. The avatars cut the picture to a circle, so put the face in the center.
3. Ask the artist before you use their work.

仓库里不带立绘，自己找图放进这个文件夹就行。少了哪张，页面上那个位置就空着，别的照常用。

| 文件 | 用在哪 |
|---|---|
| `normal.webp` | 平时，聊天气泡旁边的头像也用它 |
| `happy.webp` | 心情是开心、兴奋 |
| `jealous.webp` | 心情是吃醋、想你 |
| `sleepy.webp` | 在睡觉或暂停时，登录卡片上也用它 |
| `browsing.webp` | 正在刷 B 站 |

概览页的大图用透明底的竖图效果最好，高 600 像素以上。头像会被裁成圆形，所以脸要在图的中间。用别人的作品要先问过作者。
